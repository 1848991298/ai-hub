# AI Hub 项目规则

本目录是使用者自行维护的规则与个人技能来源。公开仓库提供通用模板，不含原作者的规则、固定技能、工程或账号配置。

- 先阅读 README，了解各模块的能力与依赖。
- `rules/global.md`：填写自己的共享规则。
- `skills/` 和 `manifest.tsv`：只加入自己有权使用与分发的技能。
- 映射前运行 `bash scripts/pull.sh --check`；确认目标后再执行 README 中的应用命令。不要覆盖现有客户端的不同内容。
- 本地凭据、数据库、账号、工程登记和台账连接放在 `.local/`，不提交到 Git。
- 修改界面、服务或采集器后，完成适用测试；提交和推送按项目使用者授权执行。
